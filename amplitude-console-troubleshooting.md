# Amplitude Console Noise

## Finding

The reported Amplitude requests are not generated by the TaskNest application. The failing requests originate from the managed Manus editor/preview shell bundle, identified in the browser stack as `spaceEditor-*.js`.

TaskNest application-source inspection found no Amplitude SDK initialization, Amplitude API URL, or `sr-client-cfg.amplitude.com` reference. The only analytics entry in the application source is the configured Umami script in `client/index.html`:

```html
<script defer src="%VITE_ANALYTICS_ENDPOINT%/umami" data-website-id="%VITE_ANALYTICS_WEBSITE_ID%"></script>
```

## Impact

The shell’s `403 Forbidden` remote-config requests and `400 Bad Request` HTTP API request are console noise from the managed editor instrumentation. They are separate from TaskNest’s tRPC requests and do not indicate a TaskNest application or database failure.

## Resolution

No TaskNest application code was changed for this issue. Removing the requests from the managed editor console requires a Manus editor/hosting configuration change. For a clean application-console check, inspect the published TaskNest domain directly rather than the managed editor preview. If the noise must be disabled in the editor itself, report the shell configuration issue through [Manus Help](https://help.manus.im).
